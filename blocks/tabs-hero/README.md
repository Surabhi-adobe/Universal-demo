# tabs-hero

Custom **tabs** block. Purpose: Tabbed homepage hero; each tab switches the heading, description and CTA shown over a background photo.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: tab label cell, then a content cell with optional background image, heading, description and CTA link; tab buttons render beneath the panels.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
