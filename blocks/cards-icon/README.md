# cards-icon

Custom **cards** block. Purpose: Row of centered icon items with title, text and link, separated by vertical dividers.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: icon image cell, then a text cell with title, description and link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
