# cards-image

Custom **cards** block. Purpose: Cards with a top photo and a text panel holding a centered title, text and button.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image cell, then a text cell with title, description and CTA button.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
